# TradingHero 直播鬼点子生成器 Skill v1 正式设计稿

## 1. 设计目标

把 2024.11-2026.06 的直播活动方案、Excel 真实玩法记录和销售结果，沉淀成一个可复用的 Codex skill。用户每周策划 TradingHero 旗舰年会员直播活动时，可以输入活动日期、基础售价、福利预算和活动目标，快速获得多个可选直播营销方案，并看到方案背后的历史依据、预期 GMV、预期旗舰年销量和风险提示。

v1 的重点不是替代人的判断，而是把“每周重新想方案”变成“按历史规律生成、再由人微调”的工作流。

## 2. 使用边界

- 只为 TradingHero 直播营销活动服务。
- 主推产品为 TradingHero 旗舰年会员，原价固定按 3690 元计算折扣。
- 输出只预测旗舰年会员 GMV 和旗舰年销量，不预测旗舰月会员。
- Excel 的“直播活动玩法简介”是实际执行主证据。
- PDF 是策划背景和灵感库；当 PDF 与 Excel 不一致时，效果归因以 Excel 为准。
- 2024 专业版、月费、课程私域案例可用于创意和链路参考，但不能直接套用到旗舰年会员 GMV 预测。

## 3. Skill 名称和触发

建议 skill 目录名：

`tradinghero-live-idea-generator`

建议 `SKILL.md` frontmatter：

```yaml
---
name: tradinghero-live-idea-generator
description: "Generate TradingHero flagship yearly live-marketing plans from historical campaign data."
---
```

触发场景：

- 用户说“帮我做本周 TradingHero 直播活动方案”。
- 用户说“生成几个直播营销玩法/鬼点子”。
- 用户给出售价、活动日期、福利预算，要求预测 GMV 和销量。
- 用户要求基于历史直播活动数据复用效果好的玩法。

## 4. 输入字段

v1 必填输入：

- 活动日期：用于判断是否月底、节日、行情节点、普通周中。
- 基础售价：用户输入，默认按旗舰年会员原价 3690 元计算折扣。
- 福利预算区间：以 50 元为一档，例如 0-50、50-100、100-150、150-200、200-300、300+。
- 活动目标：`冲GMV`、`冲销量`、`前置蓄水`、`互动增强` 四选一。

v1 可选输入：

- 是否允许低价秒杀。
- 是否允许加赠月数。
- 是否有实物礼品池。
- 是否能做课程/私密课/打卡/1元预购。
- 是否有销售或客服承接。
- 是否需要避开历史上表现差的玩法。

默认值：

- 未提供活动目标时，默认 `冲GMV`。
- 未提供福利预算时，默认 `100-200 元`。
- 未说明是否允许低价秒杀时，默认允许，但必须提示毛利和价格锚点风险。
- 未提供礼品池时，默认使用历史常见礼品类型：京东 E 卡、便携屏、黄金摆件、学习礼包、加赠月数、小额实物。

## 5. 输出格式

每次固定输出 3 个方案：

1. 稳健方案：不极端低价，强调可执行和风险可控。
2. 冲刺方案：优先使用强折扣、秒杀、限时、稀缺名额，目标是 GMV 或销量突破。
3. 互动方案：使用抽奖、盲盒、二选一、礼品叠加等增强直播氛围，但必须绑定清晰价格理由。

每个方案必须包含：

- 方案名称。
- 适用场景。
- 基础折扣售价和折扣率。
- 叠加福利清单。
- 直播玩法节奏，按开场、第一轮、第二轮、第三轮、收尾写。
- 历史对照案例，至少 2 个。
- 预期旗舰年销量：保守、目标、激进三档。
- 预期 GMV：保守、目标、激进三档。
- 成交逻辑。
- 风险提示。
- 可以直接给主播使用的口播要点。

输出末尾必须给出“推荐优先级”：

- 首推方案。
- 备选方案。
- 不建议采用的方案或条件。

## 6. 历史数据使用规则

v1 使用这些研究产物作为参考材料：

- `outputs/tradinghero_full_history/TradingHero_2024-2026_直播活动效果扩展研究报告.md`
- `outputs/tradinghero_full_history/TradingHero_2024-2026_直播活动结构化明细.csv`
- `outputs/tradinghero_full_history/TradingHero_2024-2026_玩法标签汇总.csv`
- `outputs/tradinghero_full_history/TradingHero_2024-2026_产品阶段标签汇总.csv`
- `outputs/tradinghero_full_history/TradingHero_鬼点子生成器_skill雏形_全量历史版.md`

使用原则：

- 效果归因优先读取 Excel 真实玩法标签。
- PDF 灵感标签只用于丰富玩法，不参与 GMV 预测。
- 预测旗舰年会员时，优先参考 2025-2026 中明确售卖旗舰年会员的案例。
- 2024 专业版案例只作为“课程种草、低价教育、私域蓄水”的链路参考。
- 对 PDF 未匹配、低置信度、日期疑似错配的案例，引用时必须标注“仅作背景参考”。

## 7. 生成规则

### 7.1 活动目标分流

`冲GMV`：

- 优先强折扣秒杀、阶梯价、低价名额、月底/节点冲刺。
- 推荐价格带优先 2280-2691 元。
- 必须输出清晰的购买理由，例如“今晚最低价”“前 N 名”“越早买越优惠”。

`冲销量`：

- 可比冲 GMV 更激进地使用低价、限时、名额。
- 预测销量时按基础售价反推，不使用月费案例。

`前置蓄水`：

- 优先课程/私密课/打卡/作业挑战/1元预购/加客服。
- 不以当天 GMV 作为唯一成功标准。
- 输出应包含后续大促承接方式。

`互动增强`：

- 可用抽奖、盲盒、礼品二选一、飞行棋、刮刮乐、砸金蛋等玩法。
- 必须绑定价格锚点或成交理由。
- 禁止只堆礼品而没有明确折扣或稀缺性。

### 7.2 价格规则

- 2280-2691 元：适合冲刺、秒杀、月底节点、重大促销。
- 2691-2890 元：适合强主题、限时加赠、阶梯价。
- 2890-3090 元：必须有明显福利加码或强节点，不适合普通直播直接使用。
- 3090-3250 元：风险较高，必须配合课程种草、强稀缺、私域承接或高价值权益。
- 3250 元以上：v1 默认不推荐作为主推直播成交价，除非用户明确要求保价或不做低价。

折扣率计算：

`折扣率 = 基础售价 / 3690`

例如：

- 2280 元约 61.8 折。
- 2691 元约 72.9 折。
- 3140 元约 85.1 折。

### 7.3 福利预算规则

0-50 元：

- 适合小额券、低成本周边、学习资料、抽奖资格。

50-100 元：

- 适合 50/100 元优惠券、京东 E 卡、小型周边。

100-200 元：

- 适合便携小电器、小额实物、黄金贴、桌垫、手册、加赠 15 天或 1 个月。

200-300 元：

- 适合便携屏、行李箱、黄金摆件、加赠月数、组合礼包。

300+ 元：

- 适合大奖抽奖、电视/投影仪/高价值礼品，但必须作为稀缺奖池，不应平铺到每个购买用户。

福利组合原则：

- 福利必须服务成交理由。
- 产品相关权益优先：加赠月数、指标学习礼包、订单流资料、手册、桌垫。
- 实物礼品适合增强感知，但不应替代价格理由。
- 同一方案最多保留 2-3 层福利，避免复杂到用户听不懂。

## 8. 预测规则

v1 不做机器学习模型，使用“相似历史案例估算”。

步骤：

1. 按产品阶段筛选：优先旗舰年会员相关案例。
2. 按活动目标筛选：冲 GMV、冲销量、前置蓄水、互动增强。
3. 按价格带筛选：输入售价所在价格带。
4. 按玩法标签筛选：强折扣秒杀、阶梯价、礼品选择、加赠月数、抽奖/盲盒等。
5. 取相似案例的 GMV 和销量分布。

输出三档：

- 保守档：相似案例中位数，或低置信样本时取较低参考值。
- 目标档：相似案例 75 分位附近。
- 激进档：Top 案例参考，只在低价、强节点、强承接同时成立时给出。

销量估算：

`预期销量 = 预期 GMV / 基础售价`

调整规则：

- 如果输入售价明显低于历史客单价，销量可上调，但 GMV 不自动上调。
- 如果售价高于 3090 元且没有课程/私域承接，销量应下调。
- 如果历史相似案例少于 3 个，必须标注“样本不足，预测仅供参考”。

## 9. 风险判断规则

必须提示风险的情况：

- 售价高于 3090 元，但只配置普通实物礼品。
- 用户选择互动玩法，但没有明确价格锚点。
- 用户要求高 GMV，但不允许低价、秒杀、限时、稀缺。
- 预算很低，却要求高价值实物礼品。
- 参考案例来自 PDF 灵感标签，而不是 Excel 真实效果标签。
- 参考案例来自 2024 专业版/月费阶段，却要预测旗舰年会员。
- 历史上类似玩法出现过高 UV 零销售。

高 UV 零销售参考提醒：

- 4.21 大促：三轮秒杀 2850/2950/3050，高 UV 但 0 GMV。
- 5.22 大促：3090/3140 + 礼品三抽一 + 加赠 1 个月，高 UV 但 0 GMV。
- 这类案例用于提醒：价格锚点、购买理由、销售承接可能比福利复杂度更重要。

## 11. Skill 文件结构设计

正式 skill 建议结构：

```text
tradinghero-live-idea-generator/
  SKILL.md
  references/
    generation-rules.md
    prediction-rules.md
    historical-findings.md
    output-template.md
  assets/
    TradingHero_2024-2026_玩法标签汇总.csv
    TradingHero_2024-2026_产品阶段标签汇总.csv
```

v1 不建议把完整 360 行明细塞进 `SKILL.md`。完整明细可作为外部项目资料或后续脚本资产；skill 主体只保留稳定规则和小型汇总表。

`SKILL.md` 应保持简短：

- 什么时候使用。
- 先问/读取哪些输入。
- 如何选择方案类型。
- 必须使用哪些参考规则。
- 输出格式要求。

详细规则放入 `references/`。

## 12. 验收标准

skill v1 完成后，必须能通过这些测试：

1. 输入：活动日期、本周普通直播、售价 2690、福利预算 100-200、目标冲 GMV。  
   期望：输出低价/限时/加赠月数或学习礼包方案，并引用 6.5、1.22、3.19 等历史案例。

2. 输入：售价 3140、福利预算 200-300、不允许低价秒杀。  
   期望：提示高价风险，建议课程种草、私域承接或强节点，不应只堆礼品。

3. 输入：目标前置蓄水，不要求当天 GMV。  
   期望：输出课程/打卡/1元预购/加客服链路，并说明当天 GMV 不是唯一指标。

4. 输入：只想做抽奖/盲盒互动。  
   期望：保留互动玩法，但强制补充价格锚点或成交理由。

5. 输入：月底冲刺、允许低价秒杀、福利预算 300+。  
   期望：输出冲刺方案、大奖抽奖作为稀缺奖池，并给出保守/目标/激进三档 GMV 和销量。

## 13. v1 不做的事情

- 不自动创建前端页面。
- 不接入在线数据库。
- 不做机器学习训练。
- 不预测旗舰月会员。
- 不把 PDF 方案当作真实执行结果。
- 不承诺 GMV 预测准确，只给历史相似案例下的区间估算。
