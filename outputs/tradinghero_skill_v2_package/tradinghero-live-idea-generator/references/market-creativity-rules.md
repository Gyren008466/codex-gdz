# Market Creativity Rules

Use this file only when historical mode is `不参考历史` or `混合模式`.

## How To Use Creative Expansion

- Keep the TradingHero offer clear: flagship yearly membership, price, final payment price, and benefits.
- Borrow mechanics from live commerce, but adapt them to a high-ticket software product.
- Do not let game mechanics hide the purchase reason.
- If no historical evidence is used, label the plan as a creative assumption rather than a proven pattern.

## Useful Live Interaction Mechanics

- Limited-time 立减:
  - Simple, strong, easy to understand.
  - Best for GMV.
- Benefit vote:
  - Users vote between two gift stacks.
  - Best for interaction without making benefits too complex.
- Scratch card / blind box:
  - Works when prizes are visible and rules are simple.
  - Use only 2-3 prize tiers.
- Host privilege:
  - Host unlocks an extra 0 yuan inventory gift for a short window.
  - Good for urgency without increasing cost.
- Milestone unlock:
  - If live-room comments, scans, or orders hit a threshold, unlock extra gift.
  - Good for atmosphere, but avoid making the threshold unrealistic.
- Order-time ladder:
  - First 10 orders get strongest benefit, next 10 get lighter benefit.
  - Good for urgency and scarcity.

## Creative Guardrails

- Every plan still needs a one-sentence purchase reason.
- Avoid more than three stacked benefits.
- Avoid hidden-cost gifts unless budget is explicit.
- Do not auto-use unconfirmed candidate gifts.
- If using 立减金, always recalculate final payment price and GMV basis.

## Good Creative Combinations

- GMV sprint:
  - 200 元立减金 + 0 yuan inventory gift + 30-minute limit.
- Cost-controlled conversion:
  - 100 元立减金 + 指标手册/桌垫 bundle.
- Interaction:
  - User vote between 100 元京东E卡 and 100 元立减金.
  - Explain that 京东E卡 keeps payment price unchanged, while 立减金 lowers payment price.
- Product-education:
  - 指标手册 + 订单流桌垫 + short live demo.
